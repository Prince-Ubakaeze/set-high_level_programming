The ``MyList`` class
====================

Import the class:

    >>> MyList = __import__('1-my_list').MyList

Create an empty list:

    >>> values = MyList()
    >>> values
    []

Append integers:

    >>> values.append(4)
    >>> values.append(1)
    >>> values.append(3)
    >>> values.append(2)
    >>> values
    [4, 1, 3, 2]

Print a sorted copy:

    >>> values.print_sorted()
    [1, 2, 3, 4]

The original list is unchanged:

    >>> values
    [4, 1, 3, 2]

Duplicates and negative numbers are supported:

    >>> other = MyList([3, -1, 3, 0])
    >>> other.print_sorted()
    [-1, 0, 3, 3]
